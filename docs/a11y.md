- **Lighthouse**: `web/scripts/lighthouse.mjs` writes the summary to `docs/lighthouse/summary.json`.

## Design decisions
- Charts: each one is a single tab stop with a roving tabindex, an aria label that summarises the key numbers, and a visually hidden data table as a text alternative.
- Dense marks (MC bins about 3px, FCF bars, bridge steps on phones) can't be 44px wide. Below `lg` each of these charts gets a stepper with 44px ‹ › buttons, plus "Details" on the waterfall. This is the equivalent-control exception in WCAG 2.5.8.
- `.hit` utility: grows small inline controls to a 44px pointer target using a centred `::after`, without changing layout.
- Performance work:
  - framer-motion is behind `LazyMotion`, and its features load at idle.
  - The assumptions panel, the sheet and the page chunks are lazy-loaded.
  - The current route's chunk is preloaded with modulepreload.
  - Font CSS is latin-only, and the Inter 400 and 600 fonts are preloaded.
  - The data JSON is preloaded, and the first render waits for it (2.5 s cap), so skeletons don't resize into content.
  - Charts measure their width before first paint.
  - These changes took CLS from 0.29–0.41 down to 0.
  - Radix Select and Tooltip were replaced with a native `<select>` and a small custom tooltip that is hoverable, dismissable and persistent (WCAG 1.4.13).
